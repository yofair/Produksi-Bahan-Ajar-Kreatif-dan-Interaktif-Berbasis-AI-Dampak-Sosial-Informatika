# Bahan Ajar Interaktif – Dampak Sosial Informatika

Bahan ajar interaktif berbasis HTML untuk mata pelajaran Informatika kelas X SMK.

## Fitur
- 10 slide interaktif
- Input nama dan kelas siswa
- Tujuan pembelajaran
- Materi dampak sosial informatika
- Media pendukung interaktif
- Studi kasus interaktif
- 5 soal pilihan ganda
- Skor otomatis dan feedback
- Refleksi siswa
- Halaman hasil respons siswa
- Cetak/simpan hasil sebagai PDF
- Ekspor respons dalam format JSON
- Validasi agar siswa tidak dapat melewati tahap wajib

## Cara menjalankan
Buka `index.html` menggunakan browser modern seperti Google Chrome.

## GitHub Pages
Setelah repository dibuat, aktifkan **Settings → Pages**, pilih branch utama dan folder `/ (root)`. Website dapat dibuka melalui URL GitHub Pages repository tersebut.
